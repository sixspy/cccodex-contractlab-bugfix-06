# 入站契约

> 遵守 `ops/底座生成前必读_效率与技术栈.md`。FastAPI + Vue 3 + SQLite，交付须 docker compose 一键起；库用 SQLite，不挂外置 Postgres。  
> **禁止同构换皮**：本仓主链路、表结构、接口与页面均独立，不得与其它仓共用同一套 `/api/items` 壳。

## 避开

## 互斥切口候选

- 破坏性变更直接拒收 vs 双写缓冲
- 影子只读试跑 vs 双轨分开展示
- 契约回滚整版原子切换 vs 按生产者摘流

## 缓冲口径（假缓冲修复，甲径钉死）

- 修复径选定为**甲径**：兼容模式缺字段时，批次缓冲标志与缓冲行在**同一事务**双写，缺一则整笔回滚；不留“有标志无行”。
- 乙径（先落草稿再挂行）未启用，不得与本径混用；当天不许换径，偏离即拦下并记“假缓冲偏了”。
- 标缓冲必须有行或显式草稿；**禁止有缓冲结果而无行**，也**禁止把拒收改写成缓冲**。
- 值班补行并发须排队（`BEGIN IMMEDIATE` + `batch_id` 唯一索引）；补成记“缓冲补行”，后到只记“缓冲争用”。
- 列表、缓冲队列、对账账册、调策略附页、复核卡片共用同一判定：绿 / 假缓冲，同绿同空。
- 对账按原始数据比对批次与缓冲行集合，不再只比计数，杜绝“数字对平即假绿”。

### 接口补充

| 接口 | 说明 |
|------|------|
| `POST /api/buffers/supplement` | 值班补行，排队写入，重复者记争用 |
| `GET /api/buffer-policy` / `PUT` | 读取/确认修复径；当天换径返回 409 |
| `GET /api/strategy` | 调策略附页：口径、判定、审计事件 |
| `GET /api/review` | 复核卡片：与其余四处同一判定 |

## 启动（一键）

`powershell
cd projects/05-contractlab
docker compose up -d --build
`

浏览器：http://127.0.0.1:10731/  
健康检查：GET http://127.0.0.1:10731/api/health

本机开发（可选）：

`powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --app-dir backend --host 127.0.0.1 --port 10602
python -m pytest -q
`
